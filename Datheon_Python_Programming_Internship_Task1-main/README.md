# 🎮 Hangman Word Guessing Game

## 📌 Project Description
The Hangman Word Guessing Game is a console-based Python project developed as part of the Datheon Python Programming Internship.

In this game, a random English word is selected from a text file. The player must guess the hidden word by entering one letter at a time. The player can make a maximum of 6 incorrect guesses before the game ends.

## ✨ Features
- Random English word selection.
- Displays hidden letters using underscores.
- Maximum of 6 incorrect attempts.
- ASCII art representation of the Hangman.
- Input validation for user guesses.
- Prevents duplicate guesses from counting as new attempts.
- Displays winning and game-over messages.

## 🛠️ Technologies Used
- Python
- Random Module
- File Handling
- Sets
- Conditional Statements
- Loops and Functions
